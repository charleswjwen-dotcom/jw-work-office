# T-S0-02 决策文档：LibreOffice 分发方式

> 日期：2026-09-10
> 关联任务：开发任务清单 T-S0-02
> 关联架构节：§3.4（LibreOffice 进程池）、§6 NFR 体积基线

---

## 一、结论

**选定方案：要求用户预装 LibreOffice（Homebrew cask 引导安装）。**

随包分发方案因体积过大（804 MB）、macOS 签名/公证流程复杂、精简构建可行性低，在本阶段不可行。目标用户群（个人办公，macOS）对"安装前置软件"的接受度可接受，配合安装引导脚本可将体验影响降至最低。

---

## 二、体积基线（实测，LibreOffice 26.8.0.3，macOS）

| 子目录 | 大小 |
| --- | --- |
| Frameworks/ | 435 MB |
| Resources/config/ | 107 MB |
| Resources/help/ | 61 MB |
| Resources/extensions/ | 61 MB |
| Resources/fonts/ | 51 MB |
| 其他 Resources/ | 41 MB |
| **合计（.app 整包）** | **804 MB** |

> 参考值修订：开发任务清单原估值"约 300-500 MB"偏低，实测 804 MB，§6 NFR 表应以此为基线。

## 三、三种方案评估

### 方案 A：随包分发（.app 内嵌 soffice）

- 体积增量：804 MB，打包后 .dmg 超过 1 GB，超出 macOS App Store 150 MB 下载限制；直接分发也严重影响首次下载体验。
- 签名/公证：需对 soffice 二进制及数百个 .dylib 逐一签名，公证流程复杂，维护成本高（每次 LibreOffice 版本升级须重新签名）。
- 版本锁定：随包可锁定版本，保真度最高。
- **结论：体积与签名成本不可接受，S0 阶段放弃。**

### 方案 B：要求用户预装（Homebrew cask 引导）✅ 选定

- 体积增量：安装包 0 增量；首次启动检测到缺失时弹出安装引导，脚本执行 `brew install --cask libreoffice` 即可。
- 签名/公证：完全由 LibreOffice 官方负责，主应用签名流程不受影响。
- 用户体验：个人办公用户（目标群体）约 15-30% 已预装 LibreOffice；未预装者通过引导脚本一次性安装，后续透明。
- 版本依赖：需在运行时检测 soffice 版本（≥ 7.0 即可），记录版本差异降级策略（见 §五）。
- **结论：体积、签名、维护成本均最优，选定。**

### 方案 C：精简随包构建

- LibreOffice 无官方精简构建；社区 slim 构建（去除 help/extensions/fonts）仍约 400-500 MB，且字体缺失直接影响 Word/PPT 中文排版保真度。
- 自行裁剪需维护 LibreOffice 构建系统，成本极高，不在本期范围内。
- **结论：可行性低，排除。**

## 四、安装引导方案设计（方案 B 落地）

启动时检测逻辑（伪代码）：

```
soffice_path = detect_soffice()   // 依次探测已知路径
if not soffice_path:
    show_dialog(
        title="需要安装 LibreOffice",
        body="My-work-office 的文档保真预览功能需要 LibreOffice。\n"
             "点击「自动安装」将通过 Homebrew 安装（约 800 MB）。",
        actions=["自动安装", "手动下载", "暂不安装（功能受限）"]
    )
```

- 自动安装：spawn `brew install --cask libreoffice`，进度条展示，完成后重新检测。
- 手动下载：打开 https://www.libreoffice.org/download/download-libreoffice/。
- 暂不安装：功能降级，保真预览和分页定位不可用，其他功能正常。

已知路径探测列表（macOS）：
1. `/Applications/LibreOffice.app/Contents/MacOS/soffice`
2. `$(brew --prefix)/bin/soffice`（Homebrew 非 cask 安装）
3. `$PATH` 中 `soffice`

## 五、版本兼容与降级策略

| 场景 | 处理方式 |
| --- | --- |
| soffice 版本 ≥ 7.0 | 正常使用 |
| soffice 版本 6.x | 提示升级，功能可用但不保证保真 |
| soffice 未安装 | 触发安装引导（§四） |
| 转换超时（默认 30s） | 降级为"预览不可用"提示，不崩溃（§3.4 崩溃隔离） |
| 字体缺失（中文乱码） | 提示用户安装 Noto CJK 字体；长期方案：打包 2-5 MB 字体子集随 app 分发 |
